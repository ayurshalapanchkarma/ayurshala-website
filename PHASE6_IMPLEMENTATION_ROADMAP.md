### Phase 6B: API Endpoints (Est. 2-3 days)

**Invoice Management:**
- `GET  /api/billing/invoices` — List invoices
- `POST /api/billing/invoices` — Create invoice
- `GET  /api/billing/invoices/[id]` — Get invoice
- `PUT  /api/billing/invoices/[id]` — Update draft
- `DELETE /api/billing/invoices/[id]` — Cancel invoice
- `POST /api/billing/invoices/[id]/finalize` — Finalize (atomic)
- `POST /api/billing/invoices/[id]/payment` — Record payment

**Patient Ledger:**
- `GET /api/billing/patients/[patientId]/ledger` — Complete history
- `GET /api/billing/patients/[patientId]/balance` — Outstanding

**Refunds:**
- `GET  /api/billing/refunds` — List refunds
- `POST /api/billing/refunds` — Create refund
- `POST /api/billing/refunds/[id]/post` — Post refund (atomic)

## PHASE 6 CRITICAL WORKFLOWS

### Workflow 1: OPD Billing
```
Appointment Completed
↓
Create OPD Invoice
↓
Add Consultation Charge
↓
Add Medicines (from Pharmacy)
↓
Add Procedures (if any)
↓
Finalize Invoice (atomic: ledger + balance update)
↓
Record Payment
↓
Generate Receipt
```

### Workflow 2: IPD Billing
```
IPD Admission
↓
Daily Room Charges
↓
Procedures during stay
↓
Medicines issued
↓
Final Discharge
↓
Create Consolidated Invoice
↓
Deduct Advance (if paid)
↓
Record Final Payment
```

### Workflow 3: Pharmacy Integration
```
Medicine Sale (Phase 5)
↓
Link to Patient Invoice (automatic)
↓
Add to bill_invoice_items
↓
Update Patient Ledger
↓
Update Invoice totals
```

### Workflow 4: Refund Processing
```
Patient Requests Return
↓
Create Refund Record
↓
Calculate refund amount
↓
Post Refund (atomic: reverse ledger)
↓
Record Refund Payment
↓
Generate Credit Memo
```
